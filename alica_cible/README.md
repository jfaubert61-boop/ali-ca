# alica_cible

Dossier du projet parallèle à ali-ca.

Le bouton « Importer ali_cible.json » affiche un tableau de quatre colonnes :
Kcal, Glu, Lip et Prot. Le fichier doit contenir un objet avec les champs
`Kcal`, `Glu`, `Lip`, `Prot`, `Glu %`, `Lip %` et `Prot %`. Les pourcentages
sont affichés sur la troisième ligne, avec une cellule vide sous Kcal.
